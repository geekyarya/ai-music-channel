Privacy Policy

NGR Uploader

Who this applies to

NGR Uploader is used only by the owner of the Neon Ghost Radio YouTube channel to upload that channel's own videos. It has no other users.

What Google data it uses

With the channel owner's permission (Google OAuth), the tool uses the YouTube Data API to upload videos, set their titles, descriptions, tags and privacy status, and set custom thumbnails on the owner's channel. It does not read, collect or store data about viewers, subscribers or any other YouTube users.

How credentials are stored

The OAuth refresh token is stored as an encrypted secret in the owner's private automation settings and is used only to perform the uploads described above. It is never shared with, sold to, or used by any third party.

Data retention and deletion

The tool keeps no personal data. The owner can revoke its access at any time at myaccount.google.com/permissions, which immediately stops all uploads.

Google API Services User Data Policy

NGR Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services, so the YouTube Terms of Service and the Google Privacy Policy apply.

Contact

Questions about this policy can be sent through the Neon Ghost Radio YouTube channel.
