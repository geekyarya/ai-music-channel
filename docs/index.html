NGR Uploader

Private publishing tool for the Neon Ghost Radio YouTube channel.

NGR Uploader is a personal automation tool used by the owner of the Neon Ghost Radio YouTube channel. It publishes the channel's daily music videos (title, description, tags and thumbnail) to that one channel.

It is not a public service: no one else can sign in to it, and it does not access any other YouTube accounts.
